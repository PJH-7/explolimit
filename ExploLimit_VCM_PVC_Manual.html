ExploLimit VCM/PVC v1.0은 VCM·PVC 생산공정의 GC 또는 물질수지 조성을 입력하여 정상 공기 기준 혼합 LEL/UEL을 신속히 추정하는 단일 HTML 웹앱입니다.

중요: 이 앱은 폭발방지 설계나 작업허가를 승인하는 도구가 아닙니다. 퍼지 완료, LOC/MOC, Hot Work, 밀폐공간 진입, 휴대용 검지기 보정 판단에는 사용하지 않습니다.

1. 목적과 사용범위

공정 Off-gas 조성이 바뀌었을 때, 혼합물의 가연성이 어느 방향으로 변하는지를 빠르게 비교하는 것이 주목적입니다.

GC 조성 검토

Vent, Recovery, Light-end, Dryer Off-gas의 분석조성으로 혼합 LEL/UEL을 계산합니다.

운전조건 비교

정상·기동·정지·이상반응 조성별로 LEL 변화와 가연성분 비율을 비교합니다.

HAZOP·MOC 선별

어떤 조성이 상세 검토 대상인지 우선순위를 정하는 참고자료로 사용합니다.

2. 사용 절차

1

공정 시나리오 선택 또는 초기화

예시 조성은 교육용입니다. 실제 검토 시에는 반드시 GC·물질수지 값으로 교체합니다.

2

DB 물질 추가

VCM/EDC 핵심, Oxychlorination, EDC 열분해, PVC Copolymer, Heavy-end 필터로 물질을 찾습니다.

3

전체 Stream 조성 입력

가연성, 비가연성, 산화제를 모두 포함하여 100 vol%로 입력합니다. 합계가 다르면 정규화 버튼을 사용합니다.

4

현재 주변농도 입력(선택)

주변 공기 중 전체 Off-gas 농도를 입력합니다. 검지기의 %LEL 숫자는 입력하지 않습니다.

5

결과와 데이터 품질 확인

APPROVED, REVIEW, USER, HOLD 상태와 특수위험 경고를 먼저 확인한 뒤 수치를 해석합니다.

앱에 없는 물질은 사용자 정의 물질로 등록할 수 있습니다. 분자식만으로 LEL/UEL을 계산하지 않으며, 확인된 문헌값과 출처가 필요합니다.

3. 계산 원리

3.1 가연성분 기준 혼합 LEL/UEL

전체 Off-gas 중 가연성 물질만 추출하고, 가연성분끼리 100%가 되도록 정규화한 몰분율 zᵢ를 사용합니다.

1 / LELmix = Σ ( zᵢ / LELᵢ )
1 / UELmix = Σ ( zᵢ / UELᵢ )

예: 가연성분이 VCM 80%, EDC 20%라면 각 성분의 정규화 분율과 문헌 LEL/UEL을 역수 가중합니다.

3.2 전체 Off-gas 기준 LEL

전체 Off-gas 중 가연성분 비율을 F라고 하면 다음과 같이 단순 희석 환산합니다.

LELstream = LELfuel / F
이 환산은 정상 공기 중 낮은 농도 영역에서의 1차 근사입니다. CO₂, 수증기, 염소계 물질, 산소가 포함되면 실제 화염전파 특성과 차이가 커질 수 있습니다.

3.3 전체 Off-gas 기준 UEL을 HOLD하는 이유

불활성가스가 포함된 Stream이 공기와 섞일 때는 연료 농도뿐 아니라 산소와 희석가스 농도도 동시에 변합니다. 따라서 UEL을 단순히 가연성분 비율로 나누면 실제 상부 가연경계를 잘못 표시할 수 있습니다.

비가연·산화제 성분이 포함된 경우 앱은 전체 Stream UEL을 계산하지 않고 HOLD합니다. 필요한 경우 Fuel–O₂–Inert 삼각 가연도 또는 실험자료를 사용해야 합니다.

4. 결과 해석

결과 항목의미사용법
가연성분 기준 LEL가연물 혼합물 자체가 정상 공기에서 화염전파를 시작하는 하한 추정조성 간 고유 가연성 비교
가연성분 기준 UEL가연물 혼합물의 상한 추정가연범위 폭 비교, 상세검토 선별
전체 Off-gas 기준 LEL비가연성분을 포함한 전체 Stream이 공기 중 도달해야 하는 단순 환산농도주변농도·누출계산과 비교

6. 적용 한계와 사용 금지

사용 가능

정상 공기, 상온·대기압 부근, GC 또는 설계조성이 알려진 혼합가스의 1차 비교.

상세검토 필요

산소·CO₂·Steam이 많은 Stream, 고온·고압, 수소계, 반응성·중합성 물질.

사용 금지

퍼지 완료, LOC/MOC, Hot Work, 밀폐공간 진입, 폭발방지 최종설계, 검지기 교정.

주요 제한조건

제한이유대안
정상 공기 기준산소농도가 달라지면 가연범위가 변함삼각 가연도, LOC 시험자료
상온·대기압 부근온도·압력에 따라 LEL/UEL 변화ASTM E681/E918 또는 공정조건 자료
Le Chatelier 근사상호작용과 화염속도 차이를 완전히 반영하지 않음혼합가스 실험 또는 검증된 모델
독성 미판정폭발한계와 노출기준은 별개SDS, OSHA/KOSHA 노출기준
국부 혼합 불균일 미반영실제 Vent 주변에는 농도구배가 존재현장 측정, 환기·확산 해석
아세틸렌 포함 시: 산소가 없어도 분해폭발 가능성이 있으므로 “불활성화되었다”는 결론을 내릴 수 없습니다.
